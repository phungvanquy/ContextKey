ContextKey v0.5.0 adds a refreshed interface, the new ContextKey logo, improved popup borders, and a saved **System / Light / Dark** preference under **Settings → Appearance**.

- Updated settings, translation, and chat layouts, including compact window sizes.
- Consistent branding across the app, tray, installer, and Store package.
- Theme changes apply after saving and persist across restarts. Failed saves preserve the active settings.
- A Microsoft Store MSIX package built with the registered `ITMO.ContextKey` identity and bundled WebView2.

## Downloads

- **`ContextKey_0.5.0_x64-setup.exe`**: the installer for normal Windows use.
- **`contextkey.exe`**: standalone application; requires an installed WebView2 runtime.
- **`ITMO.ContextKey_1.0.0.0_x64.msix`**: unsigned Partner Center submission package. It is not a signed installer for direct installation. Microsoft signs the Store package after certification.
- **`SHA256SUMS.txt`** and the MSIX `.sha256` file: download integrity checks. `build-info.json` records the MSIX source commit and bundled runtime.

The MSIX Store version (`1.0.0.0`) is independent of the app version (`0.5.0`). Windows build/tests and MakeAppx validation gate this release. The local browser suite passed 76 checks, and the packaging and release verification suite passed 18 checks.

Native desktop UI checks, Windows App Certification Kit, the privacy-policy URL, and Partner Center listing/certification remain outstanding. This GitHub release does not mean the app is published in Microsoft Store.

See the [Store packaging guide](https://github.com/phungvanquy/ContextKey/blob/v0.5.0/docs/MICROSOFT-STORE.md) for testing and submission instructions.

ContextKey v0.5.2 fixes Markdown rendering in chat and translation popups, adds formatted math and diagrams, and refreshes the documentation with new screenshots.

- Markdown tables now render with aligned columns and horizontal scrolling when needed. Headings, nested lists, blockquotes, task lists, strikethrough, line breaks, and escaped characters also render correctly.
- Code blocks preserve their contents and support syntax highlighting. Links open through the Windows handler, and images fit within the reply. Raw HTML remains inert, and unsafe link protocols are rejected.
- Math renders with KaTeX and Mermaid code fences show diagram previews. Rendering libraries and fonts ship locally; invalid math or diagrams retain readable source text.
- Streaming updates preserve text selection, keyboard focus, and scrolling within replies, including tables and code blocks. Existing images and diagrams remain stable as the response grows.
- The README and preview gallery now show chat, translation, code, tables, math, and diagrams in light and dark themes.

## Downloads

- **`ContextKey_0.5.2_x64-setup.exe`**: the installer for normal Windows use.
- **`contextkey.exe`**: standalone application; requires installed WebView2 and offers installation guidance if it is missing.
- **`ITMO.ContextKey_1.0.2.0_x64.msix`**: unsigned Partner Center submission candidate using shared Evergreen WebView2. Microsoft signs the Store package after certification; use the EXE installer for normal installation.
- **`SHA256SUMS.txt`** and the MSIX `.sha256` file: download integrity checks. **`build-info.json`** records the MSIX source commit, runtime mode, measured sizes, and checksum.

The Store package version (`1.0.2.0`) is independent of the app version (`0.5.2`).

## Validation

The local browser suite passed 156 checks in light and dark themes, and the packaging/release verification suite passed 21 checks. Publication is gated by Windows Rust tests, EXE and MSIX builds, MakeAppx validation, and release version/source/checksum verification.

Native Windows desktop checks, including external-link launching, keyboard/IME behavior, display scaling, missing-runtime recovery, and MSIX upgrades, remain pending. Windows App Certification Kit and Partner Center listing/certification are also outstanding. This GitHub release does not mean the app is published in Microsoft Store.

ContextKey v0.5.1 fixes chat auto-scrolling and reduces the MSIX package size by using shared Evergreen WebView2.

- AI replies preserve your reading position during streaming, completion, and errors, so you can read from top to bottom. Growing the input, attaching screenshots, and resizing the window also preserve it.
- Sending a message reveals the pending reply once. **Jump to latest** makes a one-time jump; later response chunks do not pull the transcript down.
- The MSIX no longer bundles a full WebView2 runtime. Package checks restrict its contents and enforce a 25 MiB size limit.
- If WebView2 is unavailable, a native Windows prompt offers Microsoft's Evergreen download page. Install the runtime and reopen ContextKey. The normal installer continues to provision WebView2 when needed.

## Downloads

- **`ContextKey_0.5.1_x64-setup.exe`**: the installer for normal Windows use.
- **`contextkey.exe`**: standalone application; requires installed WebView2 and offers installation guidance if it is missing.
- **`ITMO.ContextKey_1.0.1.0_x64.msix`**: unsigned Partner Center submission candidate using shared Evergreen WebView2. Microsoft signs the Store package after certification; use the EXE installer for normal installation.
- **`SHA256SUMS.txt`** and the MSIX `.sha256` file: download integrity checks. **`build-info.json`** records the MSIX source commit, runtime mode, measured sizes, and checksum.

The Store package version (`1.0.1.0`) is independent of the app version (`0.5.1`). The older v0.5.0 release and its bundled-runtime MSIX remain unchanged.

## Validation

The local browser suite passed 86 checks in light and dark themes, and the packaging/release verification suite passed 21 checks. Publication is gated by Windows Rust tests, EXE and MSIX builds, MakeAppx validation, and release version/source/checksum verification.

Windows desktop checks for missing-runtime recovery, installing WebView2 and relaunching, and upgrading from the old MSIX remain pending. Other native desktop QA, Windows App Certification Kit, and Partner Center listing/certification are also outstanding. This GitHub release does not mean the app is published in Microsoft Store.

See the [Store packaging guide](https://github.com/phungvanquy/ContextKey/blob/v0.5.1/docs/MICROSOFT-STORE.md) for runtime, testing, and submission details.
